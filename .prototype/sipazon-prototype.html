Enterprise

Reliability that never lets you down

What SIPazon brings to large, distributed and security-critical deployments.

HA Redundancy

High availability

A master and hot-standby pair with identical configuration. Intercom connections shift automatically to the redundant server on failure, and roll back when the main server recovers.

Multi-vendor

Any SIP endpoint

Manage mixed SIP endpoints from different vendor brands, and connect to Cisco, Avaya, Mitel, Alcatel-Lucent, 3CX, Asterisk, FreeSWITCH and Kamailio.

Scalability

From one door to an airport

The same platform scales from a single door entry intercom to airport and prison systems. MvM handles thousands of monitored objects.

Security

Encrypted by design

SIP TLS signalling, SRTP and ZRTP media encryption in the jPhone app, and tamper-resistant stations for high-security areas.

SIPrec

Every conversation kept

Record all incoming and outgoing calls by class of service, to local UC-series storage or external NAS.

Edge · Fog · Cloud

Deploy where it fits

Run on UC800, jNode, a virtual machine or SIPazon Cloud, across Edge, Fog and Cloud deployments.
